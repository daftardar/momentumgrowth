# موقع مومينتوم جروث — momentumgrowth.com.sa

موقع ثابت (HTML/CSS/JS) بلا أي اعتماديات أو خطوة بناء. كل ما يلزم رفعه هو محتوى هذا المجلد.

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة التعريفية كاملة (تصميم متجاوب، عربي RTL) |
| `assets/logo-full.svg` | الشعار الكامل بالألوان |
| `assets/logo-reverse.svg` | الشعار الأبيض للخلفيات الكحلية |
| `assets/icon.svg` / `icon.png` | رمز M (للأيقونة المفضلة والمشاركة) |
| `assets/pattern.png` | نمط الخلفية من هوية العلامة |

## بيانات يجب تحديثها قبل النشر

ابحث في `index.html` عن:

- `+966 5X XXX XXXX` و `tel:+966500000000` — رقم الهاتف الرسمي.
- `info@momentumgrowth.com.sa` — تأكد أن البريد مفعّل على الدومين (يظهر مرتين: في القسم وفي كود النموذج).
- ساعات العمل في قسم "تواصل معنا".

## خطوات النشر على الدومين

1. **الاستضافة:** ارفع محتوى المجلد إلى أي استضافة ثابتة (Cloudflare Pages، Netlify، Vercel، أو استضافة سعودية عادية عبر cPanel في مجلد `public_html`).
2. **DNS:** من لوحة تحكم الدومين لدى المسجّل (SaudiNIC أو الوكيل):
   - سجل `A` أو `CNAME` للجذر `@` يشير إلى الاستضافة.
   - سجل `CNAME` لـ `www` يشير إلى الجذر.
3. **SSL:** فعّل شهادة HTTPS من الاستضافة (Let's Encrypt مجاني في معظم المنصات).
4. **البريد:** أضف سجلات `MX` لمزود البريد (Google Workspace أو Zoho أو Microsoft 365) حتى يعمل `info@momentumgrowth.com.sa`.

## نموذج التواصل

النموذج الحالي يفتح برنامج البريد لدى الزائر برسالة جاهزة (mailto) ولا يحتاج خادم.
لاستقبال الطلبات مباشرة دون فتح البريد، يمكن ربطه لاحقاً بخدمة مثل Formspree أو Web3Forms بتغيير سطر واحد في الكود.

## المعاينة محلياً

```bash
python -m http.server 8765 --directory website
```

ثم افتح `http://localhost:8765`.
