# موقع مومينتوم جروث — momentumgrowth.com.sa

موقع ثابت (HTML/CSS/JS) بلا أي اعتماديات أو خطوة بناء.

## أين يعمل الموقع الآن

- **الاستضافة:** GitHub Pages من المستودع `daftardar/momentumgrowth` (فرع `main`، المجلد الجذر).
- **الدومين:** مسجّل لدى صحارى نت. سجلات DNS في لوحة DNS Manager:
  - `@` A → 185.199.108.153 / 185.199.109.153 / 185.199.110.153 / 185.199.111.153
  - `www` CNAME → daftardar.github.io
  - سجلات MX و TXT الخاصة بـ Google Workspace لم تُمس.
- **HTTPS:** تصدر شهادة مجانية تلقائياً من GitHub بعد اكتمال فحص DNS. بعدها فعّل خيار "Enforce HTTPS" من صفحة Settings ← Pages في المستودع.

## تحديث الموقع

عدّل الملفات ثم:

```bash
git add -A
git commit -m "وصف التعديل"
git push
```

يُنشر التحديث خلال دقيقة تقريباً.

## المحتويات

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية بالعربية (واجهة متحركة، تمرير ناعم) |
| `en/index.html` | النسخة الإنجليزية، مولّدة من العربية عبر سكربت ترجمة |
| `assets/lenis.min.js` | مكتبة التمرير الناعم (مستضافة محلياً) |
| `CNAME` | اسم الدومين المخصص لـ GitHub Pages، لا تحذفه |
| `assets/` | الشعارات ونمط الخلفية من هوية العلامة |

## ملاحظات

- أي تعديل نصي يُجرى في `index.html` ثم يُعاد توليد النسخة الإنجليزية (سكربت الترجمة محفوظ لدى Claude في الجلسة، ويمكن تعديل `en/index.html` يدوياً أيضاً).
- ساعات العمل في قسم "تواصل معنا" ما زالت افتراضية.

## نموذج التواصل

يفتح برنامج البريد لدى الزائر برسالة جاهزة إلى `info@momentumgrowth.com.sa` (mailto) ولا يحتاج خادم.
